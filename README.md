# Clean Air Walnut: It Starts With You!

A BIOL-6 group project website (Mt. San Antonio College, Group 1) promoting CO2
reduction and climate-change mitigation in Walnut, on the Mt. SAC campus, and in
surrounding communities.

- **Live site:** https://clean-air-walnut.github.io/ (GitHub Pages, served from this repo)
- **Campaign:** Clean Air Walnut: @CleanAirWalnut on Instagram and TikTok
- **Data:** U.S. EPA AirData, daily AQI by county, 2024–2025
- **Framework:** UN Sustainable Development Goal 13: Climate Action
